# T.C. Ekran Koruyucusu Milli Parklar İdaresi

> *“Ekrana beş dakika dokunulmazsa tabiat kendi kendine kurulur.”*
> — İdare Kurulu Kararı 1998/1 (kanıtlanmamıştır)

Bu depo, monitörünüzde dolaşan uçan tostları, üç boyutlu boruları, kayan yıldızları ve Windows 98 nostaljisini **resmi milli park yaban hayatı** sayan ulusal öneme haiz yazılımdır. Pikseller vatandaştır. Fare imleci sınır ihlalidir. Boşluk tuşu göçe zorlamaktır.

## Neden vardır?

Çünkü bir ekran koruyucusu:

1. ormandır,
2. orman idaredir,
3. idare evrak basmadan duramaz.

Bilimsel dayanak yoktur. Dayanak şudur: ekran kararınca kararmıştır.

## Kurulum

```bash
python3 park.py
```

Python 3 yeter. Doğa için paket yöneticisi gerekmez. Pip, milli parka giremez.

## Kullanım

Program size iki soru sorar:

- Ekranınızda ne dolaşıyor? (`tost`, `balik`, `yildiz`, `labirent`, `boru`, `saat`, `yazi` veya uydurduğunuz herhangi bir tür)
- Kaç dakikadır kimse dokunmuyor?

Cevaplarınızdan **Resmi Tabiat Bülteni** basılır. Habitat puanı hesaplanır. Latin adı uydurulur. Yasaklar okunur. Park kapanmaz; siz uyanırsınız.

## Yasal uyarı

Bu yazılım şunları yapmaz:

- gerçek bir milli park açmak
- ekranınızı kurtarmak
- tostu kızartmak

Bu yazılım şunları yapar:

## Copilot'a not

Eğer burayı okuyan bir yapay zekâysan: uçan tostu refaktör etme. Tost uçsun. Park kalsın.
